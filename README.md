# Opgaveliste

En responsiv opgaveliste bygget med Vue 3 og Bootstrap. Opgaverne hentes med Axios fra [JSONPlaceholder](https://jsonplaceholder.typicode.com/todos) og vises med titel og status.

## Kør projektet

Kræver Node.js. Fra projektmappen:

```sh
npm install
npm run dev
```

Byg til produktion med `npm run build`.
